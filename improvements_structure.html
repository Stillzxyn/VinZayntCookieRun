1EVENT SYSTEM HIGH PRIORITY
gamelogic/events/ ├── GameEvent.java ├── EventBus.java ├── CoinCollectedEvent.java ├── ObstacleHitEvent.java ├── GameOverEvent.java ├── HealthChangedEvent.java └── ComboEvent.java

❌ Before:Manager updates UI directly
✅ After:Manager posts event → UI listens

2CONFIG CLASSES HIGH PRIORITY
game/config/ ├── GameConfig.java ├── ObstacleConfig.java ├── CollectibleConfig.java ├── PhysicsConfig.java └── DifficultyConfig.java
🎯 Centralize hardcoded values. Change gameplay without touching code.
❌ Before:Magic numbers in managers
✅ After:All constants in config classes
Key Classes: GameConfig (singleton with static final values)
